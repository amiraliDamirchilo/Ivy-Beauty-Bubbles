# Ivy Beauty & Bubbles — Sheraton Grand Dubai (website concept)

7 static pages, English + Arabic (RTL) with a language switch.

- index.html — Home
- services.html — Services
- transformations.html — Before/after slider + filterable gallery
- reviews.html — Google reviews (4.7 from 4,492)
- about.html — The salon, team, amenities
- contact.html — Address, hours, map
- book.html — Booking request that opens WhatsApp (+971 52 743 4416)

Deploy: upload the whole folder to any static host (cPanel, Vercel, Netlify).
Arabic link: add `?lang=ar` to any page URL.

Before going live:
- Photos are linked from the salon's Google Maps listing. Download the originals
  from the owner and save them in assets/img, then replace the lh3.googleusercontent.com URLs.
- Confirm the WhatsApp number, the service list (nails/pedicure/gel, etc.) and packages with the salon.
- Remove the "Website concept by Damir" line in the footer if the client wants.
